EdgeGuard-AI is a high-performance, real-time safety compliance and computer vision analytics microservice. Powered by **YOLO-World** (Zero-Shot Open-Vocabulary Object Detection) and an intelligent spatial rules engine, EdgeGuard tracks industrial workers and detects Personal Protective Equipment (PPE) compliance—including **Helmets**, **Safety Vests**, **Goggles**, and **Gloves**—without requiring expensive offline re-training.

---

## 🔬 How YOLO-World (Zero-Shot Detection) Works

Traditional object detectors (like YOLOv8 or YOLOv11) are **closed-set** models: they can only detect the fixed set of classes present in their training dataset (e.g., COCO's 80 classes). If a closed-set model wasn't trained on safety goggles or reflective vests, it will never detect them.

### Zero-Shot Open-Vocabulary Principles
YOLO-World overcomes this limitation by connecting vision representations with **text embeddings** generated by a language model (CLIP):
1. **Text Prompt Encoding:** The user supplies arbitrary text strings (e.g., `"reflective vest"`, `"hardhat"`, `"goggles"`). A CLIP text encoder turns these strings into high-dimensional semantic vectors.
2. **Vision-Language Fusion:** As the input image passes through YOLO-World's backbone, cross-attention layers align visual features with the text embeddings.
3. **Zero-Shot Inference:** The model calculates similarity scores between image regions and text embeddings, outputting bounding boxes for classes it has never explicitly been trained on as a fixed dataset.

### 1. Vision Detector ([app/vision/detector.py](file:///d:/Projects/EdgeGuard/app/vision/detector.py))
- **Model Initialization ([detector.py:33-37](file:///d:/Projects/EdgeGuard/app/vision/detector.py#L33-L37)):** Dynamically loads `yolov8s-worldv2.pt` and injects open-vocabulary prompts:
  `["person", "helmet", "hardhat", "safety vest", "reflective vest", "goggles", "glasses", "gloves"]`.
- **Static vs. Tracking Modes ([detector.py:49-53](file:///d:/Projects/EdgeGuard/app/vision/detector.py#L49-L53)):** 
  - **Stream Mode (`is_static=False`):** Uses `self.model.track(..., tracker="bytetrack.yaml")` to maintain temporal IDs for continuous video streams.
  - **Static Mode (`is_static=True`):** Uses `self.model(frame)` directly. This prevents ByteTrack from filtering out objects on single uploaded images due to missing frame-to-frame motion history.
- **Confidence Calibration:** Confidence threshold is set to `conf=0.15` to capture low-contrast PPE items (like clear goggles or dark gloves).

### 2. PPE Compliance & Rules Engine ([app/core/rules.py](file:///d:/Projects/EdgeGuard/app/core/rules.py))
- **Spatial Containment ([rules.py:5-19](file:///d:/Projects/EdgeGuard/app/core/rules.py#L5-L19)):** `box_containment_ratio(small_box, large_box)` calculates the proportion of a detected PPE bounding box lying within a given body region.
- **Anatomical Region Partitioning ([rules.py:47-50](file:///d:/Projects/EdgeGuard/app/core/rules.py#L47-L50)):** For every detected worker bounding box `[px1, py1, px2, py2]`, the engine mathematically divides the body into target sub-regions:
  - `head_box`: Top 35% of person height $\rightarrow$ Checks for **Helmet / Hardhat**
  - `face_box`: 10% to 40% of person height $\rightarrow$ Checks for **Goggles / Glasses**
  - `torso_box`: 20% to 90% of person height $\rightarrow$ Checks for **Safety Vest**
  - `hands_box`: 40% to 100% of person height $\rightarrow$ Checks for **Gloves**
- **Violation Aggregation ([rules.py:68-90](file:///d:/Projects/EdgeGuard/app/core/rules.py#L68-L90)):** If a required item is detected, its exact bounding box is stored in `present_gear`. If missing, the target anatomical region is passed as a `MissingPPE` box for heatmap rendering.

### 3. Responsive Canvas Annotator ([app/vision/annotator.py](file:///d:/Projects/EdgeGuard/app/vision/annotator.py))
- **Dynamic Text Scaling ([annotator.py:41-45](file:///d:/Projects/EdgeGuard/app/vision/annotator.py#L41-L45)):** Calculates font scales and line thicknesses relative to each individual worker's box width (`box_width / 300.0`). This guarantees crisp, readable text whether a worker is far away or up close.
- **Granular PPE Boxes ([annotator.py:61-70](file:///d:/Projects/EdgeGuard/app/vision/annotator.py#L61-L70)):** Renders small green bounding boxes around detected items.
- **Dashed Missing Regions ([annotator.py:72-81](file:///d:/Projects/EdgeGuard/app/vision/annotator.py#L72-L81)):** Renders red dashed rectangular heatmaps (`_draw_dashed_rect`) directly over body parts missing required gear (e.g., `NO GOGGLES`, `NO VEST`).
- **Violation Summary Banner ([annotator.py:84-96](file:///d:/Projects/EdgeGuard/app/vision/annotator.py#L84-L96)):** Displays a crisp summary banner at the bottom of the image listing exact missing gear items for each non-compliant worker.

### 4. Non-Blocking FastAPI Routes ([app/api/routes.py](file:///d:/Projects/EdgeGuard/app/api/routes.py))
- **HD Upscaling ([routes.py:25-32](file:///d:/Projects/EdgeGuard/app/api/routes.py#L25-L32)):** Low-resolution uploaded images are automatically upscaled to high resolution (minimum 1200px) using `cv2.INTER_LANCZOS4` interpolation before drawing annotations. This prevents pixelation and text blurring.
- **High-Quality Encoding ([routes.py:38](file:///d:/Projects/EdgeGuard/app/api/routes.py#L38)):** Encodes resulting JPEG images at `96%` quality (`IMWRITE_JPEG_QUALITY`), avoiding compression artifacts.
- **ASGI Event Loop Protection ([routes.py:17-40](file:///d:/Projects/EdgeGuard/app/api/routes.py#L17-L40)):** Heavy image processing runs inside thread pools via `starlette.concurrency.run_in_threadpool`, keeping FastAPI's async event loop unblocked.

## 🍓 Raspberry Pi & Edge Deployment Guide

EdgeGuard-AI is optimized for low-power ARM edge devices (Raspberry Pi 4/5, NVIDIA Jetson, or Rockchip SBCs).

### 1. Prerequisites on Raspberry Pi (OS: 64-bit Debian/Raspberry Pi OS)
```bash
sudo apt update && sudo apt install -y \
    python3-pip python3-venv \
    libgl1-mesa-glx libglib2.0-0 \
    libopenblas-dev liblapack-dev
```

### 2. Environment Setup & Dependency Installation
```bash
# Clone repository
git clone https://github.com/YourRepo/EdgeGuard.git
cd EdgeGuard

# Create Python virtual environment
python3 -m venv venv
source venv/bin/activate

# Install requirements
pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Edge Optimization Tips for Raspberry Pi
- **ONNX / NCNN Export:** Export YOLO-World to ONNX or NCNN format for 3-5x faster CPU inference on ARM Cortex-A76 processors:
  ```python
  from ultralytics import YOLOWorld
  model = YOLOWorld("yolov8s-worldv2.pt")
  model.export(format="onnx", imgsz=640, simplify=True)
  ```
- **Frame Downsampling:** For RTSP streams, set target resolution to `640x360` in `app/vision/pipeline.py` to achieve ~15-25 FPS on Raspberry Pi 5.
- **Thermal Throttling:** Ensure an active cooling fan is attached to prevent thermal CPU throttling under continuous multi-worker inference.

### 4. Running the Edge Server
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 1
```
Access the dashboard on your local network at `http://<raspberry-pi-ip>:8000`.

## 🔍 Outlier Handling & Edge Cases

| Scenario | Challenge | EdgeGuard Solution |
| :--- | :--- | :--- |
| **Low-Res Images** | Text & boxes become blurry when stretched in UI | `INTER_LANCZOS4` high-definition upscaling in `routes.py` before rendering tags. |
| **Static Uploads** | ByteTrack drops detections on unrelated single images | `is_static=True` flag bypasses temporal tracker and runs zero-shot predict directly. |
| **Clear/Glass Gear** | Safety goggles have high transparency | Expanded class vocabulary (`"goggles"`, `"glasses"`) with lowered confidence threshold (`0.15`). |
| **Hands Raised** | Hands near head trigger false gear overlaps | Separate spatial regions (`head_box`, `face_box`, `hands_box`) calculated relative to worker height. |
